# Tron-2026 - AI-Powered Assistive Learning System Using T-Kernel 3.0

This project implements an AI-Powered Assistive Learning System based on µT-Kernel 3.0 (mtk3bsp2) on the STM32N657 platform.

## Overview
This repository contains the Board Support Package (BSP), Drivers, Middlewares, and Application code required to run the assistive learning system on T-Kernel 3.0.

## Structure
- `Appli`: Application level source code
- `Drivers`: Hardware specific drivers
- `FSBL`: First Stage Boot Loader
- `Middlewares`: OS and external libraries (T-Kernel)
- `Secure_nsclib`: Non-Secure Callable library
